# Network Security: Environment and Tools

- Used Windows and Kali Linux to complete practical network security labs.
- Practiced symmetric and asymmetric encryption using CrypTool, ccrypt, and OpenSSL.
- Generated and compared MD5, SHA-1, and SHA-256 checksums to examine file integrity.
- Used Nmap to discover devices, identify open ports, and examine services.
- Explored password security and dictionary attacks using iSunshare.
- Configured firewall rules and tested communication between a host and a virtual machine.
- The tools and techniques used will be introduced and demonstrated in the corresponding labs.
